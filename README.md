# SolicitorSearch

## Backend - .Net API
Requirements:
- .NET 10 SDK

To run:
```bash
cd SolicitorSearch.Api
dotnet run
```

## Frontend - Angular Web App
Requirements:

- Node ~24
- Npm ~11


To install required packages:

```bash
cd SolicitorSearch.WebApp
npm install
```

To start and open the front-end in a new browser window, run:

```bash
ng serve --open
```
